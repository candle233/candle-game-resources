# Asset Production

Read docs/ASSETS.md and harness/integrations.json. Start with a task-scoped brief and an authorized Eagle search when available; otherwise record the unavailable connection and keep a local TODO. Use only connected, reviewed providers, no assumed MCP commands. Record exact source, terms and attribution. Stage and inspect; avoid untrusted scripts. When quality is inadequate, write a complete generation prompt with assets.py todo and explicitly attempt Eagle sync if authorized. Retain pending/uncertain status. Review the actual imported Unity result; update the asset registry and confirm rights before shipping.

Use repository-relative commands from the project root. This skill requires the accompanying project Harness files; it is not a standalone game generator.
