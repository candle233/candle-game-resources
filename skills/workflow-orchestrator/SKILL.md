# Workflow Orchestrator

Read AGENTS.md and WORKFLOW.md. Inspect workflow.py status and the current task. Resolve only task-local blockers; do not freeze all gameplay. Create/fill one task contract, obtain real scope approval, start it, and route to the most specific local skill. Use one active writer per checkout. Keep failure attempts and evidence current. Do not claim done before required human reviews. Generate handoff at interruption boundaries.

Use repository-relative commands from the project root. This skill requires the accompanying project Harness files; it is not a standalone game generator.
